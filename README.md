# Dosecord

Dosecord is a personal wellbeing tracker for mood, medication, habits, and
reminders. The repository is in the middle of a deliberate implementation
reset.

The target architecture and technology choices are in
[docs/DESIGN.md](docs/DESIGN.md). The ordered delivery plan, acceptance
criteria, and current slice status are in [docs/ROADMAP.md](docs/ROADMAP.md).
Agent and contributor workflow is in [AGENTS.md](AGENTS.md).

The retired Python prototype was removed in slice M0.2; the repository now
contains only the Scala build and the documentation. Current slice status is
in [docs/ROADMAP.md](docs/ROADMAP.md) Appendix B. There is no supported local
application command until the roadmap reaches the relevant build slice. Do not
use the historical prototype instructions from git history.
