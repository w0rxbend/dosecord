# Bot API fixtures

These files have the shape of Bot API 10.4 payloads as the reference documents them
(docs/research/02-telegram-platform.md). They were written by hand: no bot token exists yet, so
nothing here was recorded from the live API. The error descriptions are the widely reported
strings and stay assumptions until the live spike of ROADMAP G1.1 replaces them.

Every identifier, name and text is synthetic.
