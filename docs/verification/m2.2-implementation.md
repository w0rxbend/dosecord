# M2.2 working interaction implementation evidence

Slice: M2.2 — Components, modals, ephemeral, idempotent sends; issue #7.
Dependencies: M2.1 and UX-00 green. Authoring used one isolated local worktree;
coordinator owns main integration. ROADMAP remains the only status authority.
This is its reviewed implementation checkpoint, not final provider qualification.

## Implemented and exercised

- Deferred originals and toast-only outcomes complete through live reply hooks.
- Visibility mismatch settles the original with neutral copy before a genuinely
  separately flagged follow-up. Original native-ephemeral intent prevents named
  content from reaching ordinary sends, persistent edits or outbox safety rows
  on expiry, delivery races, follow-up failure or lost bookkeeping.
- Hook and source-replacement requests preserve bounded text chunks and final
  controls. Distinct stable chunk nonces avoid collapsing multi-part sends;
  the single-message nonce formula is unchanged.
- Initial modal deadline is distinct from reply-hook lifetime. Missed deadlines
  retain sequential FormRunner state and count degradation. Modal submissions
  acknowledge independently, including source-less submissions after restart.
- Initial JDA callbacks record actual callback message IDs rather than webhook
  IDs; absent callback messages become typed nonfatal failures. Real pinned JDA
  serialization checks nonce enforcement, silent and preview flags.
- Disposable Postgres tests reconstruct real Application/WizardEngine and
  PgUnitOfWork over persisted form/session state, verifying ownership, stale and
  tampered controls and duplicate-action prevention. These are not live DMs.

## Container qualification

The unchanged 200 MB console-idle RSS gate initially failed on this artifact
at 204 MB. Separate M0.5 maintenance (#10) bounds the initial heap at 32 MiB
while preserving the 256 MiB maximum, SerialGC, JDK25 and non-root execution.
A matched experiment on the same M2.2 image measured 151 MB with only the
initial-heap override; the actual baseline fixed image without an override
measured 142 MB. Health readiness and disposable Flyway migrate/validate passed.
The final combined image was then built without an override and passed health,
RSS at 140 MB (143252 kB), and disposable Flyway migrate/validate. Its local
image digest is `sha256:18401ceec15d86232200a0b6d9c588a10cd9e6015250e5449dbfd4e560ae64de`;
inspection confirmed the initial/max heap flags and non-root user. Required CI
on the exact integrated main commit remains mandatory; its result is recorded
in issue #7 rather than inferred from local checks.
No production database, credentials, health records or Discord account were
used in these container checks. Owned disposable projects were cleaned.
