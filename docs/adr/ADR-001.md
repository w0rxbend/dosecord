# ADR-001: Scala 3 direct-style modular monolith on JDK 25 is the implementation language and process model (supersedes the Python decision of revision 1)

Status: Accepted
Date: 2026-09-11

## Decision

Implement Dosecord in Scala 3.8 on JDK 25 LTS as one process built with Mill 1.1.9, using Ox 1.0.6 for structured concurrency on virtual threads, upickle 4.4.3 for contracts, scalafmt/scalafix and -Werror in CI, and the Mill module graph as the enforced dependency direction. The process is splittable by role (gateway / worker) without code changes. This changes revision 1's decision. The re-run used corrected inputs verified this session — discord.py already sends enforce_nonce; matrix-nio 0.26.0 is a 7-week-old crypto migration after a 21-month gap; reusable Python is 422 + 201 lines; the brief contains no instruction to stay in Python; the owner's three active repositories (binstaller, dotbot-scala, nerd-fonts-installer-scala; last commits 2026-09-06, 2026-08-22, 2026-09-11) are Scala 3.8 / Mill / Ox / upickle / munit-scalacheck / native-image with the scalex and direct-style-scala plugins enabled; JDA 6.6.0, TelegramBots 10.3.0, Trixnity 5.8.1 and Ox 1.0.6 are live — and re-weighted lenses (Discord-first library and boundary quality 0.25, reliability incl. compile-time guarantees 0.25, owner fit 0.30, velocity/testing 0.20): Scala 7.98, Kotlin 6.98, Python 6.30, TypeScript 6.25, Rust 5.83; under revision 1's own weights Scala still leads 7.65 to 6.55.

## Alternatives

Python 3.14 asyncio (runner-up: discord.py 2.7.1 single-maintainer, aiogram 3.31 and hikari capped <3.15 one month before Python 3.15, matrix-nio 0.26 young on vodozemac, hypothesis and fastest copy iteration, no active Python work by the owner); TypeScript on Node 26 (discord.js 14.27 and grammY 1.46 are the best vendor libraries, matrix-js-sdk 42.3 is first-party with WASM crypto, zulip-js is stale so Zulip is hand-rolled — the same as everywhere — but the owner has zero TypeScript repositories); Kotlin/JVM (native Trixnity and JDA, but Gradle and no owner signal); Rust (best compile-time guarantees, slowest chat-UX iteration, teloxide stale, no Zulip crate).

## Consequences

The occurrence FSM and the schedule rule union are Scala 3 enums matched exhaustively under -Werror, so illegal transitions and unhandled rule kinds fail compilation; blocking JDBC and vendor SDK calls run on virtual threads under Ox supervision, so no single event loop can stall and a failed fork restarts the scope; java.time's ZoneRules transition API gives explicit gap/overlap detection; the owner's daily toolchain, formatting, property-testing and native-image habits apply unchanged. Costs: Matrix requires a Kotlin shim over Trixnity (spike and checkpoint at slice 7, out-of-process adapter as the escape hatch); Trixnity is single-company maintained; Zulip is hand-rolled (~250 lines); the JDA-from-Scala AI-assist corpus is smaller than discord.py's; a JVM container is ~180-250 MB RSS and native-image feasibility with JDA/Netty/Ktor is unverified; nothing from the Python repository is reused as code.
