# Dosecord quick start

The project is in a documented reset. The runnable product is not available
until the ordered work in [docs/ROADMAP.md](docs/ROADMAP.md) reaches the
corresponding green slice.

Before starting work:

1. Read [AGENTS.md](AGENTS.md).
2. Read [docs/AGENTIC_DEVELOPMENT.md](docs/AGENTIC_DEVELOPMENT.md).
3. Select the first dependency-unblocked slice in
   [docs/ROADMAP.md](docs/ROADMAP.md).

The target system is described in [docs/DESIGN.md](docs/DESIGN.md). Historical
setup commands are intentionally removed from this guide so that a new agent
does not start the retired implementation.
